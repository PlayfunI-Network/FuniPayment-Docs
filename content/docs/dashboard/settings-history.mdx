「設定變更紀錄」列出這個伺服器每一次設定修改：什麼時候、誰改的、改了哪個欄位、從什麼改成什麼。付款方式突然不見或身分組被換掉時，可以在這裡查是誰改的。

<SettingsHistoryDemo />

## 誰可以看

伺服器的擁有者。在左邊選「設定變更紀錄」。

## 每一欄的意思

桌面版是一張表，最新的在最上面：

| 欄 | 意思 |
|---|---|
| 「時間」 | 修改的時間 |
| 「版本」 | 設定的版本號。每存一次加 1，同一次儲存改了好幾個欄位時，這幾列的版本號相同 |
| 「來源」 | 從哪裡改的，見下一節 |
| 「操作者」 | 改的人的 Discord 名稱，括號裡是 Discord ID。系統自動修改時寫「系統」 |
| 「欄位」 | 改了哪一個設定，名稱跟設定頁上的一樣，例如「管理員身分組」「萊爾富超商代碼」 |
| 「原本」「改為」 | 修改前後的值 |

一次儲存改了幾個欄位，就會有幾列。手機上每一列變成一張卡片，寫著欄位、來源、改之前和改之後的值（中間用 → 隔開）、時間和操作者。

紀錄很多時，最下面有「上一頁」「下一頁」，旁邊寫著「共 4 筆 · 第 1 / 1 頁」這樣的總數。

## 來源

| 來源 | 什麼情況 |
|---|---|
| 「網頁」 | 你在後台設定頁儲存的修改 |
| 「系統」 | 機器人自動做的修改。目前只有一種：開單時速買配回傳 -3003，系統把那個付款方式關掉，見[設定：付款方式與手續費](/dashboard/settings-payment) |
| 「Discord」 | v1.0.0 以前用 Discord 的 /settings 改的。現在 /settings 只會給你後台的連結，新的紀錄不會再出現這個來源 |
| 「管理後台」 | FunI 付款系統的營運方替你修改的 |

最早的一筆通常是「建立設定」，也就是設定精靈建立這個伺服器設定的那一次，「原本」「改為」都是「—」。

## 值怎麼顯示

- 開關：「開啟」或「關閉」。
- 身分組、頻道和分類：顯示名稱，好幾個用「、」隔開，頻道前面有 #。已經在 Discord 刪掉的項目會顯示成一串數字 ID。
- 沒有值：「（無）」。
- 參數碼、檢查碼和商家驗證參數：「原本」是「—」，「改為」只寫「已變更（不顯示內容）」，不會記下實際的值。

## 常見狀況

<Callout title="付款方式被關掉了，但沒有人改過">
找來源是「系統」、欄位是那個付款方式的紀錄。有的話，是速買配還沒開通這個付款方式，機器人在開單失敗時自動關掉了。到速買配開通後，再去[設定：付款方式與手續費](/dashboard/settings-payment)打開。
</Callout>

<Callout title="頁首說明提到 Discord 的 /settings">
頁面標題下的說明寫著「網頁、Discord 的 /settings 與系統自動做的修改都會記在這裡。」/settings 的設定面板在 v1.0.0 已經移除，這句指的是以前留下的紀錄。
</Callout>

<Callout title="出現「沒有變更紀錄。」">
這個伺服器的設定還沒有任何紀錄。
</Callout>
