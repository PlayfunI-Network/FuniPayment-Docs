title: "誰可以用什麼"
description: "各身分組可以使用的指令對照。"
---

機器人用兩種東西決定誰能用指令：商家在後台選的身分組，以及 Discord 本身的權限。大部分指令看身分組，`/auto-publish`、`/dynamic-vc-rename` 和 `/dashboard` 看 Discord 的權限。

## 後台的三種身分組

| 身分組 | 在哪裡設 | 有了可以做什麼 |
|---|---|---|
| 「管理員身分組」 | [設定：基本](/dashboard/settings-basic) | 用 `/fp`、`/payment recheck`；開單時「指定付款者」；查別人的訂單和付款紀錄；代替顧客按訂單上的按鈕 |
| 「可建立訂單的身分組」 | [設定：基本](/dashboard/settings-basic) | 留空時所有人都能用 `/payment create`；選了之後，只有這些身分組和管理員身分組能用 |
| 「點數管理員身分組」 | [設定：點數](/dashboard/settings-balance) | 用 `/balance add`、`/balance set`；查別人的點數和點數紀錄；排行榜沒開放時也看得到 |

管理員身分組和點數管理員身分組是分開的。只有管理員身分組的人不能加減點數，要點數權限就把他的身分組也加進點數管理員身分組。

## Discord 的權限

有三個指令看的是 Discord 的權限，跟後台的身分組無關：

| 指令 | 要的 Discord 權限 |
|---|---|
| `/auto-publish` | 在輸入的頻道有「管理頻道」 |
| `/dynamic-vc-rename` | 在輸入的頻道有「管理頻道」 |
| `/dashboard` | 「管理伺服器」。沒有的人，Discord 不會列出這個指令 |

## 每個指令

限頻道那一欄打勾的指令要伺服器已經在後台設定好，也不能在私訊裡用。後台設了「指令頻道」時，這些指令只能在指令頻道或「開單分類」底下的頻道用。

| 指令 | 誰可以用 | 限頻道 | 其他條件 |
|---|---|---|---|
| `/fp` | 管理員身分組 | ✓ | 收款沒有暫停 |
| `/payment create` | 所有人；設了「可建立訂單的身分組」時，只有那些身分組和管理員身分組。「指定付款者」只有管理員身分組能填 | ✓ | 選的付款方式有開啟、收款沒有暫停 |
| `/payment review` | 所有人，只能查自己的訂單；管理員身分組可以查任何訂單 | ✓ | |
| `/payment history` | 所有人，只能查自己的；「查詢使用者」只有管理員身分組能填 | ✓ | |
| `/payment recheck` | 管理員身分組 | ✓ | |
| `/balance show` | 所有人；「指定使用者」只有點數管理員身分組能填 | ✓ | 點數系統開啟 |
| `/balance transfer` | 所有人 | ✓ | 點數系統和點數轉帳都開啟 |
| `/balance add` | 點數管理員身分組 | ✓ | 點數系統開啟 |
| `/balance set` | 點數管理員身分組 | ✓ | 點數系統開啟 |
| `/balance history` | 所有人；「指定使用者」只有點數管理員身分組能填。排行榜沒開放時，只有點數管理員身分組看得到 | ✓ | 點數系統開啟 |
| `/top-up` | 所有人 | ✓ | 點數系統和儲值都開啟、收款沒有暫停 |
| `/auto-publish` | 在這個頻道有「管理頻道」權限的人 | | 只能在公告頻道用 |
| `/dynamic-vc-rename` | 在這個頻道有「管理頻道」權限的人 | | |
| `/dashboard` | 有「管理伺服器」權限的人 | | 只能在伺服器裡用 |
| `/settings` | 所有人 | | |

被拒絕時機器人回的字，以及怎麼處理，見[指令不能用](/troubleshooting/command-errors)。

## 訊息上的按鈕

- `/fp` 的選單和按鈕：只有付款者和管理員身分組能按，見 [/fp 快速開單](/payments/fp)。
- `/payment history` 的翻頁按鈕：被查的人和管理員身分組能按。
- `/balance history` 的翻頁按鈕：被查的人和點數管理員身分組能按。

## 網頁後台

後台用 Discord 帳號登入。一個伺服器只有一位商家擁有者，就是在設定精靈設定它的那個帳號，只有他能看這個伺服器的訂單、報表和改設定。身分組不會讓其他人進後台。登入方式見[登入後台](/getting-started/login)。
