設定精靈是後台的「設定你的伺服器」頁，用五個步驟把一個 Discord 伺服器設定好收款：「選伺服器」「管理員與頻道」「速買配」「付款方式」「確認」。準備好速買配的資料的話，幾分鐘就能做完。

第一次登入後台會自動來到這裡。之後要再設定新的伺服器，打開 [dashboard.funipay.net/setup](https://dashboard.funipay.net/setup)，或按歡迎訊息、`/dashboard` 裡的「開始設定」。

## 誰可以用

任何登入後台的人都能打開設定精靈，但只能設定自己是擁有者、或有「管理伺服器」權限的伺服器。按「建立」時後台會再確認一次。

設定好之後，這個伺服器的後台只有你能打開。FunI 付款系統的營運方也看得到，需要時會替你修改設定，每次修改都會記在[設定變更紀錄](/dashboard/settings-history)。

## 設定步驟

每一步的必填欄位都填好，「下一步」才按得下去，按鈕旁邊會寫「請完成必填欄位」。可以隨時按「上一步」回去改。

<Steps>
<Step>

### 選伺服器

<SetupServerDemo />

畫面上列出你所在、而且機器人也已經加入的伺服器，每個都有一個標籤。只有標「可設定」的選得到：

| 標籤 | 意思 |
|---|---|
| 「可設定」 | 你能管理這個伺服器，而且還沒人設定過 |
| 「已由你設定」 | 你之前已經設定好了，下面有「前往後台」 |
| 「已由其他人設定」 | 別人已經設定過這個伺服器 |
| 「沒有管理權限」 | 你沒有這個伺服器的「管理伺服器」權限，下面會寫「需要這個伺服器的「管理伺服器」權限才能設定。」 |

點一個標「可設定」的伺服器，按「下一步」。如果你是按 Discord 裡的「開始設定」來的，而且已經登入，那個伺服器會先幫你選好。

清單裡沒有你的伺服器時，通常是機器人還沒加入。按「邀請機器人到其他伺服器」把機器人加進去，回來按「重新整理」。打開「找不到我的伺服器？」也有同樣的說明。

</Step>
<Step>

### 管理員與頻道

<SetupChannelsDemo />

這一步從伺服器裡選身分組和頻道，有四個欄位：

| 欄位 | 必填 | 畫面上的說明 |
|---|---|---|
| 管理員身分組 | 是 | 「可以替顧客建立訂單、查詢所有付款、要求速買配複查訂單。」 |
| 日誌頻道 | 是 | 「所有訂單資訊與點數異動都會顯示在這裡。」 |
| 指令頻道 | 否 | 「限制所有人只能在這些頻道或開單頻道輸入指令；留空則所有頻道都可以。」 |
| 開單分類 | 否 | 「這些分類底下的頻道都會被視為開單頻道，付款完成通知會顯示在私訊與該頻道。」 |

每個欄位都可以選不只一個。

如果你用訂單頻道（每位顧客一個頻道）收款，記得把那些頻道所在的分類選進「開單分類」。沒選的話，付款完成通知只會送到私訊和日誌頻道，訂單頻道也不會自動改名，見[收款與通知](/getting-started/get-paid)。

</Step>
<Step>

### 速買配

<SetupSmilePayDemo />

依速買配商家後台「基本資料管理」裡的資料填寫：

- 「商家代號」「參數碼」「檢查碼」：必填。
- 「商家驗證參數（推薦）」：選填，但畫面上方寫著「建議設定商家驗證參數」。它是 4 位數字，填了之後，機器人會確認每一筆付款完成通知真的由速買配送出，要跟速買配後台的「商家驗證參數」完全相同。

參數碼、檢查碼和商家驗證參數不會存在瀏覽器裡。如果中途重新整理頁面，回到這一步要再輸入一次參數碼和檢查碼，畫面會寫「為了安全，重新整理後需要重新輸入參數碼與檢查碼。」

找不到這些資料的話，打開這一步下方的「在哪裡找到？」。

</Step>
<Step>

### 付款方式

<SetupPaymentDemo />

五種付款方式預設都已開啟，手續費也填好了預設值：

| 付款方式 | 預設手續費（元） |
|---|---|
| 銀行轉帳 | 13 |
| 四大超商條碼 | 25 |
| 7-11 超商代碼 | 30 |
| 全家超商代碼 | 35 |
| 萊爾富超商代碼 | 30 |
| 7-11／萊爾富 金額超過 1000 的額外費用 | 5 |

手續費會加在訂單金額上，由顧客付。不想開放的付款方式把開關關掉就好。不用改的話直接按「下一步」，之後也能在[設定：付款方式與手續費](/dashboard/settings-payment)修改。手續費怎麼算見[手續費](/reference/fees)。

</Step>
<Step>

### 確認

<SetupConfirmDemo />

畫面列出前面填的所有內容。參數碼和檢查碼只顯示「已填寫」，不會顯示值。哪裡要改，按那一區右上角的「修改」回到那一步。

確認沒問題後，勾選「我已閱讀並同意服務條款與隱私權政策」，按「建立」。條款可以從同一區的「服務條款」「隱私權政策」連結打開。

</Step>
</Steps>

## 建立之後

按「建立」後畫面會出現「設定完成！」，接著自動打開這個伺服器的總覽頁。總覽最上面有一張「設定完成！開始使用」的清單：

- 在 Discord 用 /fp 建立第一筆訂單
- 設定商家驗證參數（推薦）
- 看一下訂單頁

做完的項目會打勾，全部做完或按「收起」後就不會再出現。下一步就照清單，[開出第一張訂單](/getting-started/first-order)。

設定精靈填的每一項，之後都能在後台的設定頁改，見[設定：基本](/dashboard/settings-basic)。

## 常見狀況

<Callout title="中途想放棄">
按左下角的「取消」，會跳出「取消設定？」。按「清除並離開」會清掉已選的伺服器和填的內容；按「繼續設定」回到原本的步驟。
</Callout>

<Callout title="今天無法再建立伺服器">
每個 Discord 帳號每天能建立的伺服器數量有上限。到了上限，打開設定精靈會看到這個畫面，寫著「今天已建立的伺服器已達上限，請明天再試。」隔天再來就好。

<DashboardShot id="setup-daily-limit" alt="後台畫面：「今天無法再建立伺服器」，下面寫著「今天已建立的伺服器已達上限，請明天再試。」和「回到首頁」按鈕" />
</Callout>

<Callout title="暫時無法設定新的伺服器">
你設定過的伺服器裡有一個被停用時，就不能再設定新的伺服器。打開設定精靈會看到這個畫面，寫著「你有伺服器目前已被停用，暫時無法設定新的伺服器。」，有疑問可以寫信到畫面上的聯絡信箱。

<DashboardShot id="setup-owner-suspended" alt="後台畫面：「暫時無法設定新的伺服器」，下面寫著「你有伺服器目前已被停用，暫時無法設定新的伺服器。」和聯絡信箱 contact@funipay.net" />
</Callout>

<Callout title="按「建立」後出現錯誤">
- 「這個伺服器剛剛已經被設定了，請選擇其他伺服器。」：你填精靈的時候，有別人先設定了這個伺服器。
- 「你在這個伺服器沒有「管理伺服器」權限，或已不在這個伺服器。」：你的權限被拿掉，或已經離開這個伺服器。
- 「你有伺服器目前已被停用，暫時無法設定新的伺服器。如有疑問請聯絡我們。」：你填精靈的時候，你的另一個伺服器被停用了。
- 「今天已建立的伺服器已達上限，請明天再試。」：今天能建立的數量已經用完。
- 「有欄位需要修正，請查看標示的步驟。」：精靈會帶你回到有問題的那一步，照欄位下面的訊息改。
- 「服務條款剛更新了，請重新閱讀後再同意。」：條款在你填的時候改版了，重新勾選同意再按「建立」。
</Callout>
