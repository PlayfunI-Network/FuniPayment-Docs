開始設定前，先準備好兩樣東西：一個你能管理的 Discord 伺服器，和一個速買配（SmilePay）商家帳號。兩樣都有的話，整個設定幾分鐘就能做完。

FunI 付款系統開放給所有人使用，不用申請或等審核，準備好就能自己開通。

## 一個你能管理的 Discord 伺服器

你要是伺服器的擁有者，或在這個伺服器有「管理伺服器」權限。邀請機器人和在設定精靈選伺服器時都會檢查這一點。

不確定自己有沒有權限的話，請伺服器擁有者幫你加，或直接由擁有者來設定。

## 速買配商家帳號

收款是透過速買配，錢會進你自己的速買配帳戶。還沒有帳號的話，先到[速買配官網](https://www.smilepay.net/)申請商家帳號，審核通過後再回來設定。

設定精靈會要你填這幾項，都在速買配商家後台的「基本資料管理」：

| 欄位 | 必填 | 說明 |
|---|---|---|
| 商家代號 | 是 | 你的速買配商家代號。 |
| 參數碼 | 是 | 機器人建立訂單、查詢付款狀態時要用。 |
| 檢查碼 | 是 | 跟參數碼一起用。 |
| 商家驗證參數 | 否，但建議填 | 4 位數字。填了之後，機器人會確認每一筆付款完成通知真的來自速買配。 |

參數碼、檢查碼和商家驗證參數只在後台填，不要貼在 Discord 頻道裡。

## 先在 Discord 建好的身分組和頻道

設定精靈只能從伺服器裡現有的身分組和頻道挑，其中「管理員身分組」和「日誌頻道」必填。還沒有的話，先在 Discord 建好：

- 一個給管理員的身分組。有這個身分組的人可以替顧客開單、查詢所有付款。
- 一個日誌頻道。所有訂單資訊與點數異動都會送到這裡，看得到每張訂單是誰付的，建議只讓管理員看得到。

付款方式和手續費都有預設值，這部分不用先準備。

## 常見狀況

<Callout title="我只是伺服器的一般成員">
設定精靈會把那個伺服器標成「沒有管理權限」，選不了。請伺服器擁有者給你「管理伺服器」權限，或請擁有者自己登入後台設定。
</Callout>

<Callout title="一個帳號可以設定幾個伺服器">
可以設定很多個，但每個 Discord 帳號每天能建立的伺服器有上限。到了上限，後台會寫「今天無法再建立伺服器」，隔天再試。見[設定精靈](/getting-started/setup-wizard)。
</Callout>
