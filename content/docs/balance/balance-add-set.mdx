點數管理員用 `/balance add` 幫成員加點或扣點，用 `/balance set` 把成員的點數直接改成某個數字。例如發活動獎勵，或修正算錯的點數。

<BalanceAddDemo />

## 誰可以用

只有點數管理員能用，也就是有後台「點數管理員身分組」裡任一個身分組的人。這組身分組和「基本」分頁的管理員身分組是分開的。設定見[設定：點數](/dashboard/settings-balance)。

## 使用步驟

<Steps>
<Step>

### 加點或扣點

輸入 `/balance add`，「指定使用者」選成員，「金額」填要加的點數。要扣點就填負數，例如 -100。想記下原因的話，再填「備註」。

</Step>
<Step>

### 直接設定點數

輸入 `/balance set`，「指定使用者」選成員，「金額」填他應該有的點數，例如 1000。機器人會自己算出要加或扣多少。

</Step>
<Step>

### 看結果

機器人在頻道貼出結果，同時私訊通知那位成員。

</Step>
</Steps>

## 參數

兩個指令的參數名稱一樣：

| 參數 | 必填 | 說明 |
|---|---|---|
| 指定使用者 | 是 | 要調整的成員。Discord 上的說明是「請輸入欲調整之用戶」。 |
| 金額 | 是 | `/balance add`：要加的點數，負數是扣點，不能是 0。Discord 上的說明是「請輸入要增加的金額 (負數可以減少)」。`/balance set`：調整後的點數，不能是負數。Discord 上的說明是「請輸入要設定的金額」。 |
| 備註 | 否 | 調整的原因。`/balance add` 的說明是「(選填) 請輸入原因」，`/balance set` 的說明是「(選填) 請輸入變更的原因」。 |

## 會看到什麼

`/balance add` 加點時，頻道裡的標題是「餘額增加成功」，扣點時是「餘額扣除成功」，下面寫著調整後的餘額、理由和執行者。沒填備註的話，理由寫「無」。

`/balance set` 的標題是「餘額設定成功」，欄位有「原始餘額」、「餘額更動」、「執行者」和「理由」。

這則結果也會送到日誌頻道，後台沒設日誌頻道就不會送，設定見[設定：基本](/dashboard/settings-basic)。

被調整的成員會收到「餘額異動通知」私訊，寫著被增加或被扣除多少點和目前餘額。私訊裡沒有理由，也沒有是誰調整的。`/balance set` 的私訊寫的是差額，例如從 700 設成 1000，私訊寫「被增加了 300 點」。成員關掉伺服器成員私訊的話收不到，但點數一樣會改。

這些調整都會記在成員的 `/balance history`，成員看到的是「管理員幫您增加了」或「管理員扣除了您」，看不到管理員的名字。

## 常見狀況

<Callout title="指令被拒絕">
- 「抱歉，您沒有權限使用此指令。」：你沒有點數管理員身分組。
- 「增減的金額不能為 0！」：`/balance add` 的金額填了 0。
- 「顧客 的商城點數不足，無法減少指定金額！」這類訊息：要扣的點數比對方的餘額多，訊息下面會寫他目前的餘額。點數不會扣成負的，要扣光就用 `/balance set` 設成 0。
- 「設定的餘額不能為負數！」：`/balance set` 的金額填了負數。
- 「顧客 的商城點數已經是 700 了！」這類訊息：設定的數字和他現在的點數一樣，所以沒有改。
- 「此伺服器尚未啟用商城點數系統！」：後台的「點數系統」還沒打開。

其他原因見[指令不能用](/troubleshooting/command-errors)。
</Callout>
