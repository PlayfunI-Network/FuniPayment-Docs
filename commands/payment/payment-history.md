# /payment history

## 查詢付款歷史 (payment history)

### 指令概述

`/payment history` 指令讓用戶查詢自己的歷史付款紀錄，幫助用戶追蹤和管理過去的交易情況。對管理員而言，此指令還能用於查詢特定用戶的付款歷史，方便進行客戶服務和訂單管理。

![payment history 指令介面](https://i.imgur.com/example6.png)

### 使用權限

* **所有用戶**：可查詢自己的付款歷史
* **管理員**：可查詢任何用戶的付款歷史

### 指令參數

| 參數     | 說明               | 必填 |
| ------ | ---------------- | -- |
| `mode` | 顯示模式（公開顯示/僅自己看到） | ✓  |
| `page` | 查詢頁數             | ✗  |
| `user` | 查詢特定用戶（僅管理員可用）   | ✗  |

### 顯示模式說明

* **公開顯示**：付款歷史訊息會在頻道中顯示，所有人都能看到
* **僅自己看到**：付款歷史訊息只有您能看到，適合在公共頻道保護隱私

### 特殊頁面

除了普通的頁碼外，系統還提供以下特殊頁面：

* **統計表**（頁碼 0）：顯示用戶的付款統計數據
* **伺服器排行榜**（頁碼 -1）：顯示伺服器內付款金額排行榜（若伺服器啟用）

### 使用步驟

#### 1. 查詢個人付款歷史

輸入指令並選擇顯示模式：

```
/payment history mode:僅自己看到
```

系統將顯示您的付款歷史記錄（第一頁）。

#### 2. 翻頁查看更多記錄

若您有多筆付款記錄，可以指定頁數查看：

```
/payment history mode:僅自己看到 page:2
```

或使用訊息下方的翻頁按鈕：◀️ ▶️

#### 3. 查看統計資料

點擊訊息下方的「統計表」按鈕，或直接指定頁碼為 0：

```
/payment history mode:僅自己看到 page:0
```

#### 4. 管理員查詢特定用戶

管理員可以使用 `user` 參數查詢特定用戶的付款歷史：

```
/payment history mode:僅自己看到 user:@用戶名稱
```

### 頁面內容說明

#### 付款歷史頁面

每頁顯示數筆付款記錄，每筆記錄包含：

* 訂單編號（可點擊查看詳情）
* 繳費時間
* 付款方式
* 付款金額

![付款歷史範例](https://i.imgur.com/example7.png)

#### 統計表頁面

統計表顯示用戶的付款統計資訊，包括：

* 總消費金額
* 已完成的付款筆數
* 待付款的訂單筆數
* 已過期的付款筆數
* 付款最大單
* 累計手續費
* 首次付款日期
* 最近一次付款

![統計表範例](https://i.imgur.com/example8.png)

#### 排行榜頁面

排行榜顯示伺服器內消費最多的用戶排名（若伺服器啟用此功能）：

* 前 10 名用戶及其消費金額
* 查詢者在排行榜中的排名

![排行榜範例](https://i.imgur.com/example9.png)

### 導航功能

查詢結果下方提供導航按鈕，方便瀏覽不同頁面：

* **回首頁**：返回第 1 頁
* **◀️**：前往上一頁
* **▶️**：前往下一頁
* **去尾頁**：前往最後一頁
* **統計表**：切換至統計表頁面
* **伺服器排行榜**：切換至排行榜頁面（若伺服器啟用）

### 常見問題解答

#### Q: 為什麼我看不到排行榜按鈕？

A: 可能原因：

* 伺服器未啟用排行榜功能
* 您不是管理員（部分伺服器限制只有管理員可查看排行榜）

#### Q: 查詢結果會保留多久？

A: 一般訊息會保留 15 分鐘，之後按鈕將失效。如需再次查看，請重新使用指令。

#### Q: 是否可以匯出歷史紀錄？

A: 目前系統不支援直接匯出功能。如有需要，請聯繫管理員協助。

#### Q: 為什麼有些訂單看不到？

A: 系統只顯示已完成付款的訂單。若要查看包含未付款或已過期的訂單，請聯繫管理員。
