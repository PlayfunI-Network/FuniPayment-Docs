# /fp

## 快速建立付款訂單 (fp)

### 指令概述

`/fp` 是為管理員設計的高效率指令，讓管理員能快速為顧客建立付款訂單。相較於標準的 `/payment create` 指令，`/fp` 提供了更簡化的流程，非常適合客服人員在協助顧客時使用。

![fp 指令介面](https://i.imgur.com/example11.png)

### 使用權限

* **僅限管理員使用**：此指令只能由具有管理員權限的用戶使用

### 指令參數

| 參數         | 說明    | 必填 |
| ---------- | ----- | -- |
| `amount`   | 付款金額  | ✓  |
| `customer` | 指定的顧客 | ✗  |

> **注意**: 若未指定顧客，系統將視為一般顧客付款，等待顧客自行選擇付款方式

### 與 /payment create 的差異

| 特性     | /fp        | /payment create |
| ------ | ---------- | --------------- |
| 目標用戶   | 管理員        | 所有用戶            |
| 參數數量   | 少 (最少 1 個) | 多 (最少 2 個)      |
| 付款方式選擇 | 客戶後續選擇     | 建立時指定           |
| 流程設計   | 互動式選單      | 一次性提交           |
| 特殊功能   | 支援點數付款     | 僅支援常規付款         |

### 使用步驟

#### 1. 建立基本訂單

輸入金額建立基本訂單：

```
/fp amount:500
```

系統將生成一個訂單，並在頻道中顯示互動式選單。

#### 2. 指定特定顧客

如需為特定顧客建立訂單：

```
/fp amount:500 customer:@用戶名稱
```

指定顧客後，只有該顧客能夠操作後續選單。

#### 3. 顧客選擇付款方式

訂單建立後，顧客（或管理員）可以從下拉選單中選擇付款方式：

* 銀行轉帳（+手續費）
* 四大超商條碼（+手續費）
* 7-11 ibon 代碼（+手續費）
* 全家 FamiPort 代碼（+手續費）
* 萊爾富 Life-ET 代碼（+手續費）
* 商城點數（若伺服器啟用）

![付款方式選擇範例](https://i.imgur.com/example12.png)

#### 4. 確認付款方式

選擇付款方式後，系統會顯示確認畫面，包含訂單金額和手續費資訊。點擊「確認並獲取付款碼」後，系統將生成完整的付款資訊。

#### 5. 使用商城點數付款

若伺服器啟用點數系統，顧客可選擇以商城點數付款：

1. 顧客選擇「商城點數」選項
2. 系統檢查點數餘額
3. 若餘額充足，顧客可直接確認使用點數付款
4. 交易完成後，系統自動扣除相應點數

![點數付款範例](https://i.imgur.com/example13.png)

### 頻道變更功能

使用 `/fp` 指令時，系統會依據付款流程階段自動進行頻道操作（若伺服器啟用相關設定）：

#### 頻道重命名

系統會根據訂單狀態自動重命名頻道：

* **選擇付款方式時**：「選擇中｜頻道名稱」
* **等待付款時**：「待付款｜頻道名稱」
* **付款完成後**：「已付款｜頻道名稱」
* **付款過期時**：「已過期｜頻道名稱」

#### 頻道分類移動

系統也會根據訂單狀態自動將頻道移至對應分類：

* **選擇付款方式時**：移至「選擇中」分類
* **等待付款時**：移至「待付款」分類
* **付款完成後**：移至「已付款」分類
* **付款過期時**：移至「已過期」分類

### 訂單過期處理

`/fp` 指令建立的訂單有效期為 24 小時。若顧客在此時間內未選擇付款方式，系統將：

1. 自動將訂單標記為過期
2. 更新頻道名稱（若啟用）
3. 移動頻道至過期分類（若啟用）
4. 顯示過期訊息

### 常見問題解答

#### Q: 顧客選擇了錯誤的付款方式，如何更改？

A: 顧客可以點擊「取消重選」按鈕，重新選擇付款方式。若已確認付款方式，則需要管理員建立新的訂單。

#### Q: 為何顧客無法看到商城點數選項？

A: 可能原因：

* 伺服器未啟用點數系統
* 伺服器未啟用點數付款功能
* 顧客點數餘額不足

#### Q: 如何快速查看顧客是否有足夠點數？

A: 管理員可以使用 `/balance show user:@用戶名稱` 指令查詢顧客點數餘額。

#### Q: 顧客看不見選單或按鈕失效怎麼辦？

A: Discord 互動式選單有 15 分鐘的時效限制。若超時，請重新使用 `/fp` 指令建立新訂單。

### 管理技巧

#### 高效率客服流程

1. 使用 `/fp amount:金額` 建立訂單
2. 引導顧客選擇付款方式
3. 顧客完成付款後，使用 `/payment recheck` 確認付款狀態
4. 系統自動處理後續流程（通知、頻道更新等）

#### 多用戶管理

管理多個顧客時，建議使用 `customer` 參數指定顧客，確保每個顧客只能操作自己的訂單。

### 相關指令

* `/payment review`：查詢訂單付款狀態
* `/payment history`：查看歷史付款紀錄
* `/payment recheck`：管理員重新檢查付款狀態
* `/balance show`：查詢點數餘額（若啟用點數系統）

### 支援與幫助
