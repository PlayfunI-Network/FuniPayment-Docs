## Global Constraints

- 只有繁體中文（`lang="zh-TW"`），台灣用語，稱呼讀者「你」。
- `output: "export"`，建置輸出到 `out/`，不能有任何需要伺服器的功能。
- 文件放在根路徑：頁面網址是 `/payments/fp`，不是 `/docs/payments/fp`。
- 版本固定：`next` 16.4.2、`react` / `react-dom` 19.3.0、`fumadocs-core` / `fumadocs-ui` 16.17.7、`fumadocs-mdx` 15.4.9（exact，不用 `^`）。
- Discord 視窗永遠深色；網站本身深色為預設，可切淺色。
- 不使用影片檔；單張截圖 ≤ 200 KB；`out/` 總大小 ≤ 20 MB。
- 禁用字詞（任何頁面、任何產生檔）：信用卡、免費試用、申請試用、NewebPay、藍新、公測期間全部免費。
- bot 上的字逐字照來源，用「」括起來；不手打 bot 的 embed 文字，一律經過 `bot-ui.generated.ts`。
- 示範商店「星光遊戲社」，人物用角色名（商家、顧客、管理員），不出現真實商家資料。
- 不修改 `funipay_site` 與 bot 專案的任何檔案。
- 每一頁文字寫完都用 `humanizer:humanizer` skill 跑過。
- 在分支 `docs-v1` 上工作；commit 前不推送。commit 訊息結尾加 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。

## Review Focus

1. **窄螢幕（375px）的 demo**：embed 與截圖在手機寬度不能溢出、不能小到看不清楚；鏡頭放大倍率在窄畫面要更高。→ Task 4 `cameraTransform` 測試 + Task 9 瀏覽器檢查。
2. **減少動態**：`prefers-reduced-motion: reduce` 時 demo 必須顯示最後一格、不能是空白或第 0 格。→ Task 4 `DemoStage` 測試。
3. **同一個故事數字一致**：/fp 選單的手續費、確認畫面、訂單 embed、付款完成通知必須是同一組金額。→ Task 5 `fillTokens` / 情境測試。
4. **7-11 與萊爾富超過 1000 元加收**：`amount + fee > 1000` 時加 `ibon_extra_fee`（預設 5），剛好 1000 不加。→ Task 5 `calculateFee` 測試。
5. **中文搜尋**：搜「條碼」「手續費」要找得到對應頁面（預設的英文斷詞會失敗）。→ Task 1 搜尋測試 + Task 9 檢查。
